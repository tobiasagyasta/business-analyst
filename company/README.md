# Durable Business Context

Use this directory for knowledge that is useful across multiple decisions. Do not copy it into decision folders. Reference exact files and headings from a Decision Brief or specialist assignment.

Context hierarchy:

1. `shared/` applies across the portfolio or ownership group.
2. `<business-id>/` applies to that business only.
3. A location-specific entry must name the location.
4. A decision-only item belongs in `decisions/<decision-id>/brief.md` or its evidence, not here.

Each entry should state its scope, source, date/freshness, and any uncertainty. Update durable context after reviewed results create reusable knowledge; do not overwrite historical evidence without retaining the source and date.

Use `IDR` / `Rp` for monetary context and state Indonesian geographic scope according to `methodology/indonesia-and-currency.md`.
