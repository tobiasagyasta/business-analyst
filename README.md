# Business Analyst

An evidence-aware decision-support workspace for multiple small businesses. It is designed for reusable business context, targeted specialist analysis, explicit human approval, and learning from results.

Indonesia is the default market. All internal monetary context and calculations use `IDR` / `Rp`; see `methodology/indonesia-and-currency.md`.

Start with:

1. Populate `company/shared/context.md` and the applicable business context file.
2. Create a decision folder from `decisions/templates/decision-brief.md`.
3. Follow `methodology/operating-workflow.md`.

The initial portfolio contains placeholders for `coffee-shop` and `breakfast-kiosk`; no business facts have been assumed.
